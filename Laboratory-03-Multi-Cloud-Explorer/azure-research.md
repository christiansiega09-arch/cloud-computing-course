# Research on Microsoft Azure

## Brief Overview

Microsoft created the cloud computing platform known as Microsoft Azure. It offers various computing, storage, networking, database, security, identity management, and application development services. Azure enables businesses and individuals to utilize cloud resources without having to maintain their own physical servers.

## Worldwide Infrastructure

Azure has data centers and cloud regions spread across the globe. These areas enable businesses to operate their apps nearer to their users. Additionally, Azure offers availability features that can help maintain services and applications even in the event of a single location's issues.

## Console for Cloud Management

Microsoft Azure services can be managed via the web-based Azure Portal. Virtual machines, storage accounts, databases, networks, and other resources can all be created and managed by users. 

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual computers that can be used to run applications and operating systems.
2. **Azure Blob Storage** – Provides object storage for files, images, videos, backups, and other data.
3. **Azure Virtual Network** – Provides networking for connecting and controlling Azure resources.
4. **Microsoft Entra ID** – Manages users, identities, authentication, and access to cloud resources.

## Three Advantages

1. **Microsoft Integration** – Azure works well with Microsoft products such as Windows Server, Microsoft 365, and Microsoft Entra ID.
2. **Hybrid Cloud Support** – Azure can connect cloud services with existing company servers and systems.
3. **Enterprise Features** – Azure provides security, identity, management, and other services useful for large organizations.

## Typical Enterprise Use Cases

Azure can be used for Windows Server applications, company websites, databases, virtual machines, Microsoft 365 environments, hybrid cloud systems, virtual desktops, and business applications. It is also useful for organizations that already use Microsoft technologies.
