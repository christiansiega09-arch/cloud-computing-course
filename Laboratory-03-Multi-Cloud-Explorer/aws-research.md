# Research on Amazon Web Services (AWS)

## Brief Overview

Amazon offers a cloud computing platform called Amazon Web Services (AWS). It provides a wide range of computing, storage, networking, database, security, and application development services. Businesses and consumers can use cloud resources with AWS without having to maintain their own physical servers.

## Worldwide Infrastructure

AWS maintains cloud infrastructure across the globe. To deliver dependable cloud services, it makes use of regions and availability zones. This enhances availability and performance and enables businesses to run their apps in various locations.

## Console for Cloud Management

One web-based tool for managing AWS services is the AWS Management Console. In addition to creating and configuring resources, users can monitor applications, check their services, and manage their AWS account. It gives users access to numerous AWS services from a single location.

## Four Core Services

1. **Amazon EC2** – Applications and operating systems can be run on virtual servers provided by Amazon EC2.
2. **Amazon S3** – Offers object storage for data, including files, backups, photos, videos, and more.
3. **Amazon VPC** – Offers a private network for communication between AWS resources.
4. **AWS IAM** – Users, roles, and permissions for AWS resources are managed by AWS IAM.

## Three Advantages

1. **Wide Range of Services** – AWS provides many services for different types of cloud projects.
2. **Global Infrastructure** – AWS has infrastructure in many locations around the world.
3. **Scalability** – Resources can be increased or decreased depending on the needs of an application.

## Typical Enterprise Use Cases

AWS can be used for websites, mobile applications, online stores, databases, backups, data analytics, file storage, and large-scale applications. Many organizations also use AWS to host applications and services without maintaining physical servers.
