# Client Recommendations

## Client A: New Business

**Suggested Platform: AWS**

Because AWS offers a wide range of services that can be launched with minimal resources, I suggest it to a startup. As the number of users increases, the business can expand its cloud resources. Additionally, AWS offers a variety of services that can assist the business in developing and maintaining its mobile application.

**Possible Services:**
- Amazon EC2
- Amazon S3
- Amazon RDS

## Client B – University

**Suggested Platform: Microsoft Azure**

The university already uses Windows Server, Microsoft 365, and Active Directory, so I suggest Microsoft Azure. Azure can assist the university in moving some of its services to the cloud and can work well with these Microsoft technologies.

**Possible Services:**
- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database

## Client C – AI Research Company

**Google Cloud Platform (GCP) is the suggested platform**

Because GCP creates applications for machine learning and artificial intelligence, I suggest it. AI workloads and high-performance computing can benefit from Google Cloud's services and computational resources.

**Possible Services:**
- Compute Engine
- Vertex AI
- Google Kubernetes Engine (GKE)

## Client D – Global E-Commerce Company

**Suggested Platform: AWS**

Because the business serves clients all over the world and requires highly available infrastructure, I suggest AWS. When the number of users grows, AWS's worldwide infrastructure and services can automatically expand.

**Possible Services:**
- Amazon EC2 Auto Scaling
- Elastic Load Balancing
- Amazon S3
